# Agent instructions

- Inspect files, Git status, branches, remotes, package scripts, and current guidance first. Preserve user changes.
- Work on a focused feature branch from stable main; do not merge significant PRs without owner approval.
- Use current compatible dependencies, TypeScript, reusable UI, pure domain functions, and browser-local demo state.
- Label fictional data and simulated advice. Never add credentials, real student data, real authentication, backend services, or deployment.
- Test affected behavior while developing. Before commits run formatting, lint, type checks, relevant tests, and production build; verify committed state. Before pushing run the full applicable suite.
- Inspect important screens in light/dark and mobile/tablet/desktop. Check keyboard, contrast, reduced motion, and storage corruption.
- Report branch, files, commits, executed checks, PR link, and limitations honestly. Do not claim remote CI passed without observing it.
